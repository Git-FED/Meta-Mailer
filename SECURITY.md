# Security Policy

Never store secrets in this repository. Use environment variables or a secret manager for integrations. Redact private addresses and tokens from screenshots and logs.

PRIVATE / INTERNAL: Do not publish credentials, private inbox addresses, tokens, screenshots with personal data, or connector settings without review.

If an incident is suspected, stop sending, preserve relevant evidence without forwarding suspicious content, and contact the project owner.
