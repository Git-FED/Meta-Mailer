# Dark Animated Background

A standalone, dependency-free visual asset for future documentation or project presentation. It uses layered radial gradients, animated aurora ribbons, a star/noise field, and cursor-responsive glow. It is not a website deployment and has no network calls. Open `index.html` locally to preview.
