## Intentionally omitted from the public footer

- Facebook is omitted per the project instruction.
- The personal Substack is not placed in the public footer.
- The private Matrix URL is never placed directly in the public footer.

## Private Matrix rule

The Matrix destination is available only through `private-communities.html`, which requires:

1. An 18+ self-attestation checkbox.
2. A country selection.
3. Eligibility against Canada, Switzerland, Russia, Iran, Somalia, or Turkmenistan.
4. Successful checks before the Matrix destination is revealed.

This is a user-interface and routing gate, not legal age verification, identity verification, or a substitute for provider or jurisdictional compliance.

## Visual behavior

The public footer uses shortened pill buttons, animated glow effects, an infinitely looping marquee, responsive columns, hover states, and reduced-motion support.
