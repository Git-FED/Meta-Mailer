# Glossary

**From:** visible sender identity. **Reply-To:** address receiving replies. **Forwarding:** inbound delivery to another mailbox. **SMTP:** outbound mail transport. **Send mail as:** Gmail identity configuration. **Ma​​iled-by:** transport indicator. **List:** recipient dataset. **Suppression:** addresses excluded from sending.
