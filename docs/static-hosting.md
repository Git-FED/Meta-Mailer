# Static Hosting Notes

The root `index.html` is compatible with GitHub Pages and Cloudflare Pages. All primary navigation and CTA destinations are HTML pages. External support links intentionally open provider pages in a new tab. The site has no server-side payment logic; provider widgets handle checkout.

The repeated scrolling ticker is CSS-only and respects `prefers-reduced-motion`.
