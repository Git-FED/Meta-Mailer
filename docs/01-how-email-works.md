# How Email Works

A message can have a visible From identity, a Reply-To identity, transport metadata, and a receiving mailbox. Cloudflare Email Routing handles inbound forwarding for the domain. Gmail handles the private mailbox and, when configured, outbound send-as behavior. These are separate layers and must not be conflated.
