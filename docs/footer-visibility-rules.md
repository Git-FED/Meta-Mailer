# Footer Visibility Rules

The animated public footer includes public destinations, premium landing pages, public contact mailboxes, public media links, developer Discord, and a link to the gated Private Communities page. Facebook is intentionally omitted, and the personal Substack is not placed in the public footer.

The Matrix URL is never placed directly in the footer. `private-communities.html` requires an 18+ checkbox and an eligible-country selection before revealing it. This is a self-attestation and routing gate, not legal verification.
